# DTEN_SupermarketSales_Project

Exploratory Data Analysis project for my Data Science & Analytics internship with Daryl Tech & Educational Network (DTEN).

## About

This project analyzes 1,000 transactions from a supermarket chain with three branches, covering January to March 2019. I explored the data to find patterns around branch performance, customer behaviour, and sales timing.

## Dataset

Supermarket Sales Dataset (Kaggle), 17 columns including branch, city, customer type, gender, product line, payment method, and total sale amount.

## Tools

Python, Pandas, Matplotlib, Seaborn

## Key Findings

1. The three branches perform at a similar level, with Branch C slightly ahead.
2. Gender-based buying patterns differ by product line. Health and beauty skews unexpectedly toward male customers.
3. Customers split fairly evenly across Ewallet, Cash, and Credit card payments.
4. Sales peak on Saturday and dip to their lowest on Monday.
